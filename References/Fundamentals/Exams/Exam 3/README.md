# Fundamentals Exam 3 source index

The Exam 3 bank uses the blueprint and the 18 supporting files supplied in `/Goldfarb/Fundies/Exam 3`. This development collection contains text companions for all 19 files; original PowerPoint, Word, and PDF bytes remain in the supplied source collection and have not been published by this task. The source inventory records original filenames, byte sizes, SHA-256 values, and companion paths.

Text companions retain slide headings and extracted notes for traceability. Notes may be misplaced or contain mismatched answer letters; those letters are not authoritative keys. Generated questions were written from teaching concepts, not copied from the review slides. Empty image slides have no extracted teaching text and are not used as sole evidence for generated items. Open a question reference to view its text companion; the citation names the relevant teaching slide or transcript segment.

See [source inventory](../../../../assets/question-banks/audits/fundamentals-exam-3-sources.json), [blueprint](../../../../assets/question-banks/blueprints/fundamentals-exam-3-standard.json), and [implementation record](../../../Design%20Documentation/12-FUNDAMENTALS-EXAM-3.md).
