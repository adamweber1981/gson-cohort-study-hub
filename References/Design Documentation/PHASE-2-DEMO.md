# Phase 2 — Synthetic Demo Exam

This file documents six **synthetic UI-testing questions**, not course-verified nursing exam content. The same six question templates appear under Fundamentals, Health Assessment, Pharmacology, and Pathophysiology. The order and answer choices are randomized at attempt start.

1. **Multiple choice:** option B is correct.
2. **Select all that apply:** A and C are correct; exact-set grading.
3. **Matching:** 1–A, 2–B, 3–C.
4. **True/false:** false; a submitted answer is locked.
5. **Dosage calculation:** 100 mg divided by 50 mg/mL equals 2 mL.
6. **Case-study question:** select an answer and explicitly submit to see feedback.

These questions verify UI mechanics only and must not be represented as verified clinical study content. They are not replacements for the existing standalone exams.
