## Narrated presentation

`Pharm Behavioral Health - Narrated.pptx` is 31,331,201 bytes and is stored in five original-byte parts because of the upload connection size limit. The presentation, including embedded narration, is not recompressed or edited.

- In the [practice exam](https://adamweber1981.github.io/gson-cohort-study-hub/exam.html?bank=pharmacology-exam-3-standard&v=pharm3-sources-20261029), open **References**, then select the narrated presentation **Download** button. The browser checks the reconstructed size and SHA-256 before offering the original `.pptx`.
- To reconstruct from a repository checkout or downloaded ZIP, run `python reconstruct_narrated.py` in this folder. The script verifies every part and the final file.
- [Reconstruction manifest](Pharm%20Behavioral%20Health%20-%20Narrated.pptx.parts.json) contains the exact part sizes and hashes.

Original SHA-256: `8ecd137b5a75970a04b651130f1bacf94ce7a93a16cf3ebe38056e8aefcfb381`.

## Source and naming policy

Original course materials remain unchanged and may contain brand names or historical material. Generated Exam 3 questions and medication selectors use generic names. Source availability does not establish that every statement in a source has been independently clinically validated.
